# EcoSim - Agent-Based Ecosystem Simulation

A real-time ecosystem simulation demonstrating **Advanced Data Structures and Algorithms** in C++.

## Key Features
- **Quadtree** for O(log N) spatial partitioning
- **1D Cellular Automata** for cache-friendly danger pheromone diffusion
- **Finite State Machines** for decentralized agent behavior
- **O(1) swap-and-pop** deletion for mass die-offs
- **Lotka-Volterra** population dynamics

## Tech Stack
- C++17
- Raylib (Rendering)
- CMake (Build System)
